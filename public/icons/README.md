# icons/

Ikon PWA — generate dari logo PT Aden Service saat Phase 6.

Wajib:
- icon-192.png            (192x192)
- icon-512.png            (512x512)
- icon-512-maskable.png   (512x512, beri padding aman ~10-20% agar tidak terpotong)

Di /public (root):
- favicon.ico
- apple-touch-icon.png    (180x180, untuk iOS)

Tips:
- Latar ikon sebaiknya solid (mis. #140D0A atau #EA580C) agar konsisten di home screen.
- Uji maskable di https://maskable.app sebelum rilis.
- Placeholder .gitkeep boleh dihapus setelah ikon asli ditaruh.
