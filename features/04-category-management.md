# Feature 04 — Category Management

## Purpose
Master kategori tool (mis. Compliance, Inspection, Training, Dashboard, HR, F&B, Operations).

## Fields
- Category ID
- Name (per bahasa jika perlu)
- Slug
- Order
- Active

## Rules
- Kategori configuration-driven; tidak hardcoded di komponen.
- Kategori yang masih dipakai tool tidak boleh dihapus tanpa reassign.
- Urutan kategori dapat diatur (order).
