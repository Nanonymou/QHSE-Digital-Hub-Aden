# Feature 05 — Search & Filter

## Search
Berdasarkan: Name, Description, Category, Tags.

## Filter
- Category
- Status
- Tags

## Sort
- Terbaru (release date)
- Nama (A-Z)
- Paling sering dibuka (opens)

## Rules
- Search debounced (mis. 200-300ms).
- Kombinasi filter + search bekerja bersamaan.
- Empty state mengarahkan ("Coba kategori lain / hapus filter"), bukan "No result" polos.
