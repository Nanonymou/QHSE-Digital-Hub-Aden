# Feature 12 — Notification & Tool Updates (Future)

## Phase
Future module.

## Purpose
Memberi tahu user saat ada tool baru atau update penting pada tool.

## Ideas
- Badge "New" pada tool baru (berdasarkan release date).
- Changelog ringkas per tool.
- Future: email / WhatsApp / in-app notification.

## Rules
- Notifikasi tidak menggantikan source-of-truth status tool.
- Reminder harus idempotent.
